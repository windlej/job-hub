# Career Dashboard Tracker

This tool could track multiple career pages by monitoring them. Since GitHub Pages is static, we can:

1. Manually add URLs as we find them (current approach)
2. Add a "Careers Dashboard" section that links to each company's careers page
3. Track which pages we've checked with notes
