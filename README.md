# Spokane Job Tracker

A simple, client-side tool to track IT job opportunities in Spokane, WA and beyond. Built with vanilla HTML, CSS, and JavaScript - no backend needed. Data is stored locally in your browser.

## Live Site

[https://windlej.github.io/job-hub/](https://windlej.github.io/job-hub/)

## Features

- Add, edit, and delete job opportunities
- Track application status (Interested, Applied, Interviewing, Offer, Rejected, Closed)
- Filter by status and company
- Quick access to job URLs
- Pre-configured with local companies: URM, NoaNet, F5, TierPoint, Avista, Compunet, OSOS, WSDOT
- Works on desktop and mobile

## Usage

1. Visit the [live app](https://windlej.github.io/job-hub/)
2. Fill out the job form with company, title, URL, location, status, etc.
3. Your jobs are automatically saved in your browser's localStorage
4. Filter and manage as you apply!

## Data Storage

All data is stored in your browser's localStorage. Nothing is sent to any server - it's completely private to your device.
